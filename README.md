# MakeTogether — clickable hi-fi prototype (SI 582)

Front-end only (no backend).

```bash
npm install
npm run dev
```

Open the printed URL. Desktop shows a phone frame; phones get full screen.

## Photos
Free Unsplash photos in `public/img/` (sources in `public/img/CREDITS.md`). Replace any file with the same name to swap a photo; a missing file falls back to a cream placeholder.
